## 原本と検証

全sourceのSHA-256はconfigに記録。`metadata/build-official.py`は原本を読み取るだけで、保持部分のRGBAを変更せず16px透明余白を付加する。髪2枚のみ隣接部品を除く多角形選択を使用。出力PNGを再デコードし画素一致を検証する。描画時だけ配置・倍率を調整し、生成・再描画・色調補正はしない。

首元・袖口・腿とブーツの陰影は別シート由来の微差が残る。静止表示では接合するが、可動時の裏面・関節連続性は保証しない。アニメーション用の可動域確認は次工程。
