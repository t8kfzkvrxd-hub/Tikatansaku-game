# v0.35.4 素材説明の欠損表示修正

## 原因と修正範囲

敵ドロップ由来の素材には `desc` がないものがある。能力値もないと `getItemStatSummary()` が `undefined` を返し、倉庫のテンプレートリテラルで文字列化されていた。

共通表示関数だけを修正し、説明が文字列でない場合や欠損値そのものの文字列（undefined/null/NaN）は空文字を返す。説明がある場合は加工せず保持する。装備の能力値表示は変更しない。素材定義・解禁・確率・レシピ・保存形式は変更していない。

リポジトリ規則に従い `GAME_VERSION` を0.35.4へ更新し、更新履歴へ表示修正を追加。GitHubへはpushしない。

## 変更ファイル

- `js/ui/itemPresentation.js`：欠損説明の安全な空文字化。
- `js/core/config.js`：バージョン・更新履歴のみ。
- `test_material_routes.html`：全素材定義の要約、欠損値、既存説明保持、倉庫表示を追加検証。
- `test_structure.py`：今回の明示的な表示修正だけを旧ソース比較の許容差分へ追加。

## 検証対象

全素材定義を走査するため、通常・上位レアリティ・ボス・部位由来・未解禁を含む説明有無を、解禁フラグを書き換えず検証する。共有先は倉庫/所持品、装備スロット、キャラクター装備候補。既存画面の回帰も再実行する。

個人ブラウザのセーブは使わず、隔離Chromeで新規・旧・ストーリー完了形式を読み込み、その後の部品検証は共通前提へ正規化する。新規通し・再案内防止・REPLAY中立性は専用テストで確認する。
