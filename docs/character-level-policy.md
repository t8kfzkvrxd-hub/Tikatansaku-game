# v0.14.0 成長・敵倍率・開始地点

- 保存キーは `ABYSS_ROGUE_SAVED_V2` のまま。`chapter.characters[characterId]` の `level` / `exp` を共通利用し、`characterLevelVersion: 1` を追加。
- 永久加護の購入・表示・保存・効果、鑑定選択、遺品保護、再抽選、商人優待、血の祭壇の永久能力付与を削除。旧装備に既に付与済みの数値は変更しない。
- 旧購入費は当時の価格式で一度だけ全額返還。到達0/100/300/600/900/1000FをLv1/10/25/35/45/48へ区間線形換算。旧Lvと旧加護のHP/ATK/DEFを維持できるLvのうち最大を採用。
- 旧エルナがLv50超の場合のみ、失うHP/ATK/DEFを `training.legacyHp/legacyAtk/legacyDef` へ固定継承。再購入や追加強化は不可。既存の装備・育成拡張フィールドを保持。
- 主人公の1Lv成長はHP10/ATK2/DEF1。エルナは従来のHP5/ATK2/DEF0.5（合計を切捨て）を維持。会心・吸血・状態異常は装備側。
- 次Lv必要EXP = `30 + 12L + 2L²`。Lv50以上はさらに `1000 + (L-50)*100` を加算。指数増加なし。
- 討伐EXP = `(12 + 階層*0.12) × 通常1 / 精鋭1.6 / ボス4`（四捨五入）。主人公と同行キャラへ同額。上限では余剰を蓄積しない。
- 1000Fストーリーボス撃破記録 `bossFirstKills[1000] === true` でLv100上限。第1章100Fクリアだけでは解放しない。50以降は `progressionSource: 'abyss'` の戦闘のみ。将来の深度報酬は `grantCharacterExperience(id, amount, 'abyss')` を利用。
- 1〜1000Fで各10階あたり通常6戦・精鋭1戦・ボス1戦の計算シミュレーションはLv47。周回・戦闘回避により実Lvは変わる。現在の実装範囲は100Fまでであり、1000F攻略バランスを実プレイ検証した意味ではない。

## 敵スケール

エリアデータの通常敵基礎値（敵種・エリア差）に共通の区間階層倍率 `1 + (floor - area.min)*0.015`、ATK難易度/GREED補正を適用。エリア内通常敵の各能力最大値を基準に、最後に精鋭HP1.9/ATK1.5/DEF1.4倍を適用。弱い通常種との比率はこれ以上になる。

精鋭は既存固有能力に加え3T周期の予告強撃（1.35倍）。ボスは既存ギミックを維持し、研究弱体化後でも精鋭を上回る最低値を保証。研究所表示も同じ計算を利用。

代表通常敵（各エリア最後の通常種）との比較。数値順はHP / ATK / DEF。GREED0、難易度1。ボスは研究所Lv5適用。

| 階層 | 通常 | 精鋭 | ボス |
|---|---|---|---|
| 10 | 48 / 15 / 3 | 92 / 23 / 5 | 251 / 26 / 9 |
| 50 | 272 / 85 / 23 | 517 / 128 / 48 | 1737 / 141 / 53 |
| 100 | 488 / 160 / 48 | 1080 / 245 / 80 | 5210 / 270 / 88 |
| 300想定 | 1778 / 583 / 174 | 3930 / 893 / 290 | 18980 / 983 / 319 |
| 500想定 | 3068 / 1006 / 300 | 6780 / 1541 / 500 | 32750 / 1696 / 550 |
| 1000想定 | 6293 / 2064 / 615 | 13905 / 3161 / 1025 | 67175 / 3478 / 1128 |
| 深淵1200想定 | 7583 / 2487 / 741 | 16753 / 3809 / 1235 | 80945 / 4190 / 1359 |

100F超は最終エリアを延長した計算負荷・序列テスト。新エリア実装時に固有データを設定する。実100階の全通常種・GREED0/3・難易度1.4でも逆転0件を検証。

## 開始地点

開始地点は従来どおり1F・11F・21F…91F。5F・15F…95Fの帰還門とは別。対応ボス撃破またはその開始階への実到達で解放。UIと出撃処理は `canWarpTo` / `unlockedWarpFloors` を共通利用し、旧 `maxUnlockedFloor: 30` だけでは解放しない。

新規は1Fのみ。10F到達のみでは11Fを先行解放せず、10Fボス撃破で11F解放。20/30Fも同様。既存進行は最高到達・ボス撃破記録から再計算。
