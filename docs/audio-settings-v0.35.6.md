# v0.35.6 音設定の保存・復元

## 修正範囲

v0.35.5の施設会話帯・REPLAY音声制御を維持。保存処理がなく再読込で音ON／BGM 0.35へ戻っていた問題だけを修正。UI、台詞、音源、ゲーム進行の仕様変更なし。commit/pushなし。

- 保存キー：`ABYSS_ROGUE_AUDIO_SETTINGS_V1`（localStorage、ゲームセーブと分離）。
- 保存対象／初期値：`mute: false`、`bgmVolume: 0.35`、`seVolume: 1`。SEの1は既存各音の音量を維持するマスター倍率。
- `js/ui/audioSettings.js`で起動時に同期読込。Audio生成・再生より前に復元。
- `setMasterMute` / `setBgmVolume` / `setSeVolume`で即時保存。新しい音量UIは追加しない。
- SEは共通ゲインへ接続。ミュートではBGM停止＋SEゲイン0。
- REPLAYの一時フェード値は保存しない。終了／中断で保存音量へ戻り、保存ミュートも維持。
- 数値以外／非有限値は項目単位で既定値、有限値は0〜1へclamp。不正JSONも安全に復元。有効な他項目は維持。
- ストレージ利用不可時は例外でゲームを停止させず、当該セッション内のみ設定を適用（永続化は保証不可）。
