# v0.34.1 ロビー表示調整（ローカル）

- 背景の炉・倉庫扉・酒場・店・研究設備・書庫・迷宮入口を広い透明ホットスポットで操作。中央魔法紋を既存召喚画面への入口にした。
- 常時ラベルは施設名のみ。次の目標、鍛冶推薦、派遣完了、酒場報酬を該当施設付近に表示する。
- 260msの選択発光・周辺減光後に既存遷移へ接続。選択中は入力を遮断し、ホームへ離れた場合は遅延遷移を破棄する。
- 背景は固定。炉3.1秒、火の粉4.5秒、酒場3.7秒、研究所7秒、入口霧11秒、魔法粒子8秒、召喚紋6.3秒。既存SD idleを維持し影の5.3秒変化を追加。reduced-motionでは停止する。
- セーブ・施設解禁・召喚・探索・戦闘ロジック、元画像は変更しない。GitHubへpushしていない。
