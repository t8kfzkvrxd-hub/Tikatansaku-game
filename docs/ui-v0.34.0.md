# v0.34.0 UI整理・検証結果

ローカル実装。GitHubへのcommit/pushなし。着手前の監査は [ui-v0.34.0-audit.md](ui-v0.34.0-audit.md)。

## 表示と導線

- ホーム：開始2操作と設定を優先。更新情報は設定へ。
- ロビー：次のボス／解禁通知／派遣完了を1件表示。探索と装備、おすすめへの入口をまとめ、施設7件・SD・既存機能は保持。
- 鍛冶屋：キャラ別おすすめ最大5件を初期表示。理由→能力差→必要素材→入手先→比較／作成→装備の流れ。「すべて」で全カタログ、強化・派生・覚醒・特性処理は展開して利用。
- 推薦：製作可否は既存craftingIssue、素材はmaterialCount、完成判定はcompletedBuildStateを再利用。作成可能を優先し、完成・あと1タグ・主方向強化・能力改善・新方向・空き部位の順。素材不足5個以内の候補も扱い、現在の完成ビルドを解除する候補は除外。能力差は装備の基礎値で、総能力比較は詳細側。
- 装備：キャラと7枠、HP/ATK/DEFを優先。スマホ横は概要と枠を横に並べる。Lv/EXP・同行設定・詳細効果を展開式へ。
- 戦闘：HP・実際の次行動・部位・4コマンドを優先。タグ列は非表示にして詳細を残す。完成効果／探索強化発動を短く通知。既存の部位弱体化・ログ・状態表示を再利用。
- 倉庫・図鑑・召喚：整理操作、高位コレクション、記録、長い保証説明を展開式へ。確率・派遣時間・受取導線は保持。

## 探索の選択

- 通常戦闘の道に、安全／危険の差を追加。危険は3戦、敵ATK×1.3・獲得G×1.5。安全は1戦、敵ATK×0.85・獲得G×0.75。
- 残り戦数は探索強化ボタンから確認。効果中は新しい道効果で上書きしない。素材の抽選率は変えない。
- 既存の戦闘ルート保証・チュートリアルの指定ルート・ボス・帰還ポータルは保持。
- 探索強化は24種類。3撃破ごとに未取得3候補から1つ。装備シナジーの同じ評価処理・上限へ接続し、二人の戦闘計算は独立。
- 帰還・敗北・新規出撃でリセット。永久保存しない。現段階では再読み込みでも消失することをUIに明記。
- 初期導線の短い案内を探索HUDへ。宝箱の説明を現在の素材報酬仕様へ修正。
