# v0.34.2 探索強化・鍛冶場の学習導線

ローカル実装。GitHubへのpushは行っていない。

## 探索強化

3撃破ごとに未選択回数を加算。戦闘・報酬画面を遮らず、探索／安全地点へ戻ってモーダルが閉じた後に3択を自動表示する。選択後は次の回数を順次処理する。同じ候補の連打は1回のみ。「あとで」で閉じることはできるが、未選択中のルート選択・安全地点からの続行はロジック側でも拒否し、選択へ戻す。未選択通知と小型の取得済み強化詳細を維持する。帰還・敗北・再読込時のリセットは既存どおり。

## 鍛冶場

- トップは対象SD、現在武器、おすすめ武器最大3本。全装備・防具・アクセ・お気に入り等は既存分類から参照可能。
- 推薦は既存の作成可否、能力差、主ビルド、完成／あと1タグ、完成解除回避を継続し、現在方向と合う次の派生を少し優先する。理由を表示する。必ず3本に水増しせず、適切な候補がなければ探索／全装備へ案内。
- 武器詳細にHP／ATK／DEF比較、戦い方、派生元・現在・子ノード、目標、素材を表示。フルツリーは実在parent関係のみ、4枝ずつ・内部横スクロール。隠し未解禁ノードは名前・性能を非表示。
- 47タグ全件に短い日本語説明。25完成ビルドには要約・用途・弱点・推奨行動・扱いやすさ／火力／耐久の目安を追加。星は実測Tierではない。
- 派生先が寄与する完成ビルド、現在装備の不足タグと役割、利用可能な所持候補のタグ数を分けて表示。所持タグが揃っても同時装備可能とは断定しない。
- 目標は `craftProgress.weaponGoals.player/elna` に既存save/load APIで保存。無効IDを解除し、項目のない旧セーブも許容。鍛冶場とロビーの鍛冶場通知に表示する。
- 素材詳細から到達済みの目的階方面へ案内。既存の解放済み出発地点を選び、既存出撃画面へ接続する。任意階への新規ワープは作らない。
- 作成成功後は装備比較／派生／鍛冶場へ。装備・親装備消費・覚醒確認・ロック保護の処理は変更しない。
- 完成ビルド初発見は短い通知。既存装備で既に成立しているものを初回ロード時に大量通知しない。
