## 実効果と品質

- 出血：頭の会心・胴の吸血・腕の蓄積・脚の回避。既存出血アクセの新規製作データに上限/蓄積補助。
- 追加攻撃は即時追加ヒット、追撃は状態異常を条件に予約して敵行動前に消費。
- summonは影の分身ログ/フローティングと倍率補助。speedは行動間隔を変えず「速撃」に改名。
- pierceは完全無視ではないため「防御貫通」に改名。
- 複合タグ集合276→241。単独を含め287パターン。完全重複候補0件。
- 既存装備の強化値・ロック・追加特性・履歴・主人公/エルナの装備状態を保存/ロード確認。保存形式変更なし。
- 今後の製作は再配分後の親/派生先を使用。旧IDは読み込み可能。
- test_build_balance.html：47タグの発動条件下で実行結果が変わること、新装備製作、旧セーブ、出血、追撃、グラフを確認。
- test_game.html / test_equipment.html / test_awakening_reset.html / test_structure.py 成功。
