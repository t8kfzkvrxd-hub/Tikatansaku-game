# 召喚・自動周回 v0.28.0

設定は `js/data/summons.js` の `SUMMON_CONFIG`、召喚獣は `SUMMONS` に集約。外見・色・体格・画像パスは `summon-image-catalog.md` を参照。画像は未生成、プレースホルダー使用。

## 報酬基準

手動100%＝現在の通常敵素材テーブルによる1分1戦。装備、端末速度、部位・エリート補正は含めない。通常敵3体の素材を均等配分し、レア度ごとの独立抽選へ効率を乗算する。端数試行は端数×確率で抽選し、期待値を時間に比例させる。

|レア度|通常Common|Rare以上|ボス|
|---|---:|---:|---:|
|Common|20%|10%|5%|
|Rare|30%|15%|8%|
|Epic|40%|20%|12%|
|Legendary|50%|30%|18%|
|Mythic|60%|40%|25%|
|Abyssal|70%|50%|35%|

得意は+10ポイント、鉱山コウモリの鉱石特化のみ+20ポイント（Commonでも対象通常素材40%となりRare汎用30%を超える）。複数一致も1回だけ。最終上限70/50/35%。素材分類は `SUMMON_SOURCE_TAGS` で全100敵へ明示。通常＝Common、レア＝Rare以上。特殊＝Epic以上。素材解禁は既存のクリア判定を使用し、装備直ドロップは追加しない。

ボスは30分1機会相当。指定範囲に含まれる手動撃破済みボスだけを対象に既存ボス抽選（確定枠も含む）へボス効率を適用する。自動報酬では確定取得にならない。通常敵試行へ混ぜない。派遣でボス撃破・階層解放・EXP・Gは増やさない。

## 保存と安全性

20Fボス撃破で解放。無料ミニスライムは受取ボタンで一度だけ。単発5,000G／10連45,000G。派遣費無料、10/30/60/180/360分、同時1体。

既存 SAVE_KEY の `summonSystem` へ所持・専用契約石・お気に入り・4段階天井・開始終了時刻・固定報酬・受取履歴を追加。旧セーブは空の初期値を補完。契約石の消費・成長は将来用。

天井：Epic以上50、Legendary以上100、Mythic以上250、Abyssal500。該当以上を排出したカウンタだけリセット。複数到達は最上位優先、各レア内均等。

派遣開始時に報酬を確定保存、受取後にジョブ削除。同一操作の多重実行防止、Web Locksによる召喚操作のタブ間排他、召喚revision競合拒否、保存失敗時のロールバックを使用。Web Locks非対応ブラウザでは更新を案内し、購入・受取を実行しない。

時計逆行を検知。前進改変の完全検出はサーバーなしでは不可だが、何年進めても予約済み1派遣分を超えず、自動再派遣しない。UIの残り時間のみ更新し、バックグラウンド探索ループはなし。
