# 探索2.0の背景登録

`js/data/explorationAreas.js` に表示用エリア10帯を定義。既存の敵・エリア・セーブ定義とは別管理です。現在は1〜10Fの通常ルート画面のみ有効です。安全門・ボス・チュートリアルと観測装備の追加枠は既存仕様を使用します。

各エリアの `backgrounds` に `{src, position, label}` を2〜3件登録すると、新しいルート生成ごとに抽選します。同じルートの再描画では変更しません。現状は既存ホーム画像1枚を仮使用しています。

`effects` は `mist / dust / torch / blue / red`、`titles` は既存ルートtypeごとの名称候補、`lines` はエルナの短い台詞。台詞は探索更新時30%で選択し、生存して同行中のみ表示します。新画像の生成やセーブ形式変更はありません。

既存の独立した採取ルートはありません。採取処理を新設せず、既存宝箱・イベント・敵報酬による素材入手を維持しています。新ルート追加時は既存探索処理と `EXPLORATION_ROUTES` の両方に接続が必要です。
