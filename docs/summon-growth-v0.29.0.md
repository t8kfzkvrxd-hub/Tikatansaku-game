# 召喚成長 v0.29.0

契約Lv1→2→3→4→5の必要専用石は1/2/3/5（累計11）。Lv2で得意+2pt、Lv3で時間−5%、Lv4で得意さらに+3pt、Lv5で通常敵3体の素材源を50/25/25%で優先選択可能。完全指定ではない。最大Lvの専用余剰石は1個→汎用石1個、汎用石2個で不足専用石1個を代用する。既存石・お気に入り・所持を保持。

時間短縮で実時間あたり効率が上限を超えないよう、名目時間当たり効率を `min(通常効率, 上限×時間係数)` に制限。既に上限の召喚獣は短縮した分だけ報酬を調整する。Lv5は素材の抽選先変更で高レアにも用途を残す。派遣中の強化は保存済み報酬・時刻へ遡及しない。

天井50/100/200/300。過去の350/500等はカウント値を保持し、次回にAbyssal保証。上位排出で下位カウンタもリセット。

## G収入概算

実測のプレイ時間統計はない。以下は60撃破/時・無補正・安全帰還・戦闘Gのみの比較モデル。1体 `12 + floor×6`。宝箱、イベント、売却、討伐依頼、装備、GREED、移動や施設滞在時間は除外。実際の全プレイヤー平均ではない。

|191〜199（195）|70,920|0.63h|19.04h|0.47%|0.71%|

安全地点は除いた戦闘階の平均。ボスも同じG式だが上表からは除外。1時間30撃破なら収入半分・必要時間2倍。

注意：現行GREED3はgoldRate+220%、賞金方針はさらに×1.5。深層例では約340,416G/時、300天井予算は約3.97時間。黄金シナジー3部位の追加+250%も成立するなら約606,366G/時、約2.23時間。G増加装備・一時イベントでさらに短縮し得る。序盤は重く深層金策では数時間、という大きな差がある。今回G収入・召喚価格の追加調整はしていない。天井予算は一度もAbyssalを引けなかった場合の最大予算で、通常は途中排出があり得る。
