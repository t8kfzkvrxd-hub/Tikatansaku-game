# v0.13.0 素材・武器進行

- 階層は100Fまで。素材解禁は到達階ではなく既存の `bossFirstKills`（100Fは章クリアでも可）で判定する。300F・500F・1000Fは通常プレイで解禁できない将来設定。
- 未解禁ランクの新規素材はEpic等の解禁済みランクへ制限。所持済み素材・装備は削除しない。旧「深淵の核」は既存の通貨残高を維持し、ランク素材とは区別する。
- 初期装備を除く装備報酬は素材へ変換。古代鍵・黒卵・王冠など非装備の遺物は維持（通常宝箱の古代鍵は1%）。旧固定装備29種を同じIDの製作レシピへ移行。旧ランダム装備は所持継続できるが、新規抽選入口はない。
- 基本武器103種＋テンプレート生成の上位派生964種。1,067種を手作業で追加したものではない。将来解禁のレシピも集計に含む。
- 既存の通常派生は+0。新しい上位派生は強化値・追加特性・派生履歴を保持する。強化の新規購入上限は+10のまま。
- 吸血率25%、1行動あたり最大HP8%が上限。ボスでは吸血率を半減し、経過ターンに応じてさらに減衰（30Tで無効）。与ダメージ0では回復しない。オーバーヒールの盾は最大HP15%まで。
- 47ビルドの刻印は鉄の剣を起点とするデータ生成派生。既存武器の主ビルドは維持し、別系列に猛攻・血誓の上位分岐を持たせる。
- 武器種22種は適性データ。現在実際に存在する武器種数とは別。召喚/分身は確率追撃型で、同行キャラや召喚ユニットの追加ではない。

集計は `weapon-audit-before.json` / `weapon-audit-after.json`。後者にはレア度×ビルド、武器種×ビルドの分布も含む。
