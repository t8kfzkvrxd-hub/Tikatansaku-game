# 戦闘2.0 表示基盤

`js/ui/battleUI.js` は既存 `renderCombatReadout` の表示を拡張する。戦闘コマンドのDOMとハンドラ、行動ロック、HP・状態差分、ビルド表示、ログは既存処理を使用する。

背景は `battleBackground` → 探索背景へフォールバック。敵は `enemyImage` → 既存アイコンへフォールバック。背景・キャラ画像は変形しない。左右HUD、中央敵、部位耐久、4コマンド、追加行動メニューを配置する。

## 検証

- `test_battle2.html`: 740×360 / 844×390 / 932×430 / 1366×768 / 1920×1080。通常敵・エリート・ボスの配置、44px操作領域、敵行動予告、エルナの被弾・瀕死・気絶、メニューと戦闘離脱。
- `test_combat_ui.html`: 攻撃者、実ダメージ、被ダメージ、会心、炎追撃、吸血、出血・炎上、シールド、ログ上限、表示消滅、表示によるセーブ書込みなし。
- `test_input_combat.html`: 連打防止、4行動のロック、エルナの攻撃・被弾・気絶。
- `test_part_break.html`: 部位選択、耐久減少、本体ダメージ、破壊、弱体化、5解像度の操作領域。
- `test_build_visibility.html`: 発動状態、詳細画面、ジャストガード、分身表示、主人公・エルナの計算分離。
- `test_responsive_ui.html`: 全5解像度で各3回の回転・ホーム往復、施設モーダル、装備、探索と戦闘の重複判定を通過。

Chromeの隔離プロファイルで確認。PCと740×360のスクリーンショットを目視確認。iPhone Safari / Android実機の描画・ブラウザバー変化・長時間性能は未確認。ゲームロジック・セーブ形式・素材抽選は変更していない。
