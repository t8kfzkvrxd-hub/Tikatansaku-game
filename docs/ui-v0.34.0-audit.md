## 施設Lvの依存（削除前の必須置換対象）

- 鍛冶屋：強化、追加特性、特性再抽選、高位能力強化。表示だけでなく実行ガードも置換が必要。
- 道具屋：傷薬・護符、持込上限、煙玉・解毒薬、上級傷薬。
- 酒場：討伐カウント/受取、救助報酬、短期・エリート・ボス依頼。
- 研究所：敵詳細、次ボス、ボスHP−15%、部屋予測、深層解析。敵生成もLvを参照。
- 倉庫：容量、製作、装備解除、持ち帰り超過、旧ロード時の容量再計算。
- 旧Lvデータは読み込み可能のまま、移行時に装備・素材を削除しない。既存容量を縮めない。

## 再利用する既存機能

- 素材数/ロック判定：materialCount、製作可否：craftingIssue、入手先：materialSources。
- キャラ別装備：characterEquipment、完成条件：completedBuildState。推薦用に別の完成条件を作らない。
- モーダル：showChapterModal、共通safe-area/viewport/横画面ブレークポイント。
- 現在のセーブは拠点中心だがchapter.checkpointが探索状態を保持する。探索限定効果の保存境界は明示して扱う。
