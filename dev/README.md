# エルナ開発確認

`elna-face.html`をHTTPで開く。本番index.htmlから読み込まない独立ページ。
正式画像のみを使い、親コンテナ全体で縮尺を統一する。顔の差分は使用していない。

顔アニメーションの成功条件は未達。目・眉・口の設定はnull。採用済みの、元の描画を自然に隠せる局所差分が確定するまで座標を推測しない。
`blinkElna()`、`setElnaTalking(true)`、`setElnaExpression('smile'|'surprised'|'sad')`はsupported:falseを返して理由を表示する。正常動作を装うダミーのタイマーはない。通常表情と正面視線は基準画像そのまま。

局所的な光だけ5.2秒周期で変化する。画像の色データ・形状は変更しない。reduced-motionと手動チェックで光を停止できる。

`test-elna-face.html`は表示基盤の検証用。顔アニメーションの成功テストではない。1920×1080、1366×768、844×390、932×430、740×360、縦→横での縮尺、操作、未対応機能の明示を検証する。

目の開眼線を半目・閉眼の透明画像だけで隠すことはできず、口・眉も同様。face-baseはassemblyVerified:falseで別シート由来のため、正式な顔の置換には使用しない。右閉じ目はない。左右視線差分もない。これらを生成・反転・追加切り出しで補っていない。
